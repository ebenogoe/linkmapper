# Trait values by genotype

Trait values by genotype

## Usage

``` r
plot_effect(df, marker, trait, dark = FALSE)
```

## Arguments

- df:

  Result of
  [`genotype_effect()`](https://ebenogoe.github.io/linkmapper/reference/genotype_effect.md).

- marker:

  Marker name, for the title.

- trait:

  Trait name, for the axis.

- dark:

  Colours for a dark background.

## Value

A ggplot object.
