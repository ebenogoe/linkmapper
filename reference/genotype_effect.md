# Trait values by genotype at a marker

Trait values by genotype at a marker

## Usage

``` r
genotype_effect(res, marker)
```

## Arguments

- res:

  An `lm_qtl` from
  [`scan_qtl()`](https://ebenogoe.github.io/linkmapper/reference/scan_qtl.md).

- marker:

  Marker name.

## Value

A data frame with `genotype` and `value`.
