# Marker positions on a map

Marker positions on a map

## Usage

``` r
map_positions(m)
```

## Arguments

- m:

  An `lm_map` from
  [`order_groups()`](https://ebenogoe.github.io/linkmapper/reference/order_groups.md).

## Value

A data frame with one row per marker: linkage group, order, marker,
position (cM) and distance to the previous marker.
