# Check that a file can be read

Kept from Linkmapper 0.1 for scripts that use it. Prefer
[`read_cross()`](https://ebenogoe.github.io/linkmapper/reference/read_cross.md).

## Usage

``` r
validate_lm_file(path)
```

## Arguments

- path:

  Path to a MAPMAKER or onemap file.

## Value

A onemap object.
