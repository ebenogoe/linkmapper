# linkmapper: Point-and-Click Linkage Mapping and QTL Analysis

A 'shiny' application and a set of plain R functions for building
genetic linkage maps and locating quantitative trait loci in F2
intercross, backcross and recombinant inbred line populations. It wraps
'onemap' (Margarido et al. 2007
[doi:10.1111/j.2007.0018-0661.02000.x](https://doi.org/10.1111/j.2007.0018-0661.02000.x)
) for segregation tests, two-point analysis, grouping, ordering and map
estimation, and 'qtl' (Broman et al. 2003
[doi:10.1093/bioinformatics/btg112](https://doi.org/10.1093/bioinformatics/btg112)
) for interval mapping and composite interval mapping with permutation
thresholds. Results can be exported as figures, tables, a self-contained
HTML report and an R script that reproduces the analysis.
