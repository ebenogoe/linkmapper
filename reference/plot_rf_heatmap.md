# Recombination fraction heatmap for one linkage group

Markers are in map order. Darker cells mean tighter linkage.

## Usage

``` r
plot_rf_heatmap(m, lg, dark = FALSE)
```

## Arguments

- m:

  An `lm_map`.

- lg:

  Linkage group name, for example `"LG1"`.

- dark:

  Colours for a dark background.

## Value

A ggplot object.
