# Missing data plot

Missing data plot

## Usage

``` r
plot_missing(q, threshold = NULL, dark = FALSE)
```

## Arguments

- q:

  Result of
  [`qc_summary()`](https://ebenogoe.github.io/linkmapper/reference/qc_summary.md).

- threshold:

  Optional cut-off to draw.

- dark:

  Colours for a dark background.

## Value

A ggplot object.
